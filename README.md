# 짱짱이 문화센터

`짱짱이-문화센터.html`은 데이터·스타일·동작을 포함한 독립 HTML입니다. `dist/index.html`은 같은 페이지의 배포용 파일입니다. 기본 조건은 12개월 미만·2026 겨울학기이며, 이후 59개월까지 3개월 구간과 정확한 월령을 선택할 수 있습니다.

## 지점과 수집 데이터

필터는 아이 월령·정확한 월령, 놀이 유형·수강 형태의 쌍으로 배치합니다. 지역·문화센터는 별도의 같은 행에 배치합니다. 놀이 유형 옆의 수강 형태는 1회 체험과 2회 이상 강좌를 구분합니다. 지역은 서울과 인천·부천으로 선택하며, 인천·부천은 두 도시의 지점·강좌를 함께 검색합니다. 카드에는 실제 도시를 표시합니다.

브랜드별 24개 지점을 버튼으로 선택합니다. 여러 지점은 합집합으로 조회하고 동명 지점은 브랜드로 구분합니다. 버튼의 숫자는 현재 월령·요일·학기 등 검색 조건에 맞는 강좌 수입니다. 지역·브랜드를 바꾸면 해당 범위를 벗어난 선택을 정리합니다.

- 현대백화점·더현대: 1,962개. 공개 문화센터 목록과 더현대 서울·중동·압구정 CH1985를 별도 조회했습니다. 248개는 비용 상세를 추가 확인했습니다. 더현대 서울의 12개월 미만 강좌는 현재 겨울 조건에서 0개, 수집 기간 전체에서 63개입니다. 빈 결과에서 기간을 전환할 수 있습니다.
- 롯데백화점: 1,410개. 서울 10개점·인천·부천 중동의 겨울 영유아 대표 강좌 727개에서 세부 반을 확장했습니다. 각 반의 실제 JSON API로 월령·일정·비용을 확인했습니다. 원문이 대표반으로 열리면 해당 월령·시간의 세부반을 다시 선택해야 합니다.
- 신세계 아카데미: 184개. 서울 본점·강남·타임스퀘어의 가을·겨울 ‘개월’ 검색을 확인했습니다. 타임스퀘어 목록 186개 중 최소 월령 60개월 이상 2개를 제외했습니다. 본점·강남의 해당 검색은 0건이며 전체 강좌가 없다는 의미는 아닙니다. 첫 화면의 점검 안내와 달리 공식 공개 검색 API와 상세는 정상 응답했습니다. 1인 요금·최소 참여인원이 있어 가족 총액은 미확정으로 표시합니다.
- 롯데마트: **계양점만 83개**. 겨울학기 전체 514개 목록을 순회해 명시 월령이 있는 강좌를 수집했습니다. 영아 정규반과 1일 체험을 포함하며 할인 전 수강료는 따로 표시합니다.

최종 데이터는 3,639개입니다. 종강·폐강·종료일이 지난 강좌는 화면 실행일(서울) 기준으로 제외합니다. **수집 스냅샷이며 자동 갱신·실시간 잔여석 확인은 지원하지 않습니다.** 월령이 명시되지 않은 강좌는 누락될 수 있습니다. 공식 원문과 개별 수집 시각은 상세에서 확인할 수 있습니다.

## 검색 버튼

필터 상단과 하단에 검색·초기화 버튼을 표시합니다. 월령·지점·요일·검색어 조건은 선택 중에는 결과를 바꾸지 않으며, 검색 버튼이나 검색어 입력창의 Enter로 적용합니다. 변경된 조건은 안내문으로 표시합니다. 검색 후 결과 영역으로 이동하고, 초기화는 기본 월령·겨울학기·전체 지점으로 즉시 복원합니다. 결과 정렬과 관심 활동은 바로 적용됩니다.

## 비교 기준

월령·요일·주말·시간·지역·브랜드·지점·유형·회차·검색, 찜, 최대 3개 비교, 총액·회당 총액 정렬을 지원합니다. 재료비 충돌이나 인원별 요금 조건이 있으면 총액을 미확정으로 처리하고 총액 정렬의 뒤로 보냅니다. 표시 수강료 정렬은 인원 기준이 다를 수 있음을 안내합니다.

성향 매칭은 제목의 활동 키워드에 근거한 보조 정렬입니다. 효과나 적합도를 보장하지 않으며 환경 정보가 부족한 ‘천천히 적응’에는 성향 순위를 매기지 않습니다. 찜·비교는 현재 브라우저에 저장됩니다.

## 갱신

Python3와 requirements.txt를 사용합니다. 공개 요청만 사용하며 동시 접속 2개·최대 재시도 3회로 제한합니다. 현재 조회 조건은 2026 가을·겨울이므로 차학기에는 파라미터와 페이지의 수강 시기 옵션을 함께 수정해야 합니다.

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/crawl.py
.venv/bin/python scripts/crawl_lotte.py --refresh
.venv/bin/python scripts/crawl_mart.py
.venv/bin/python scripts/crawl_shinsegae.py
.venv/bin/python scripts/assemble.py
.venv/bin/python scripts/check_data.py
```

원본은 data/*.json, 최종 데이터는 dist/courses.json과 dist/data.js에 동일하게 생성합니다. 롯데백화점은 --refresh를 생략하면 로컬 캐시에서 재개하며, 현대·마트·신세계는 실행할 때 새로 요청합니다. 갱신 스크립트는 자동 배포하지 않습니다. 공식 HTML/API가 바뀌면 파서 수정이 필요합니다.

## 검증

수정본 역할별 검토: 레드 9.2·블루 9.2·실버 9.2/10. 소스·정보구조 평가이며 독립 사용자 조사나 데이터 완전성 인증은 아닙니다. CUA 실제 브라우저에서 다중 지점 합집합, 동명 지점 구분, 브랜드 변경, 기간 전환, 인원별 비용 표시를 확인했습니다. 1440px·375px에서 가로 넘침이 없고 지점 버튼은 44px 이상입니다.


## 페이지 로드 자동 수집 (2026-11-01)
배포 사이트는 Vinext/Cloudflare Worker 서버와 D1 작업 큐, R2 스냅샷을 사용합니다. 프론트 원본은 public/이며 dist/는 생성된 배포 산출물입니다.

페이지를 열면 저장된 결과를 먼저 표시하고 /api/refresh로 공식 사이트 수집을 시작합니다. 진행 중인 작업이 있으면 공유하고, 브라우저가 /api/refresh/step을 호출하여 4개 병렬로 최대 12개씩 수집합니다. 창을 닫으면 다음 접속에서 이어집니다. 정기 실행은 없습니다. 완료 후 성공한 브랜드만 교체하고 실패 브랜드는 원래 강좌·확인시각을 보존합니다.

범위는 기존 2026 가을·겨울/2027년 2월까지이며 학기 전환 시 검색 기간 설정을 갱신해야 합니다. 실시간 잔여석은 수집하지 않습니다. 공식 사이트가 접근을 제한하거나 형식이 바뀌면 오류로 표시하고 기존 결과를 유지합니다.

검증: node --import tsx scripts/test-live.ts (공식 응답), node --import tsx scripts/test-refresh.ts (격리된 로컬 D1/R2 통합), npx tsc --noEmit, python3 scripts/check_data.py. Sites 공식 build-site.mjs로 빌드·패키징합니다.

오프라인 단일 HTML 파일은 이전 수집 스냅샷이며 서버 자동 수집 기능은 배포 사이트에서 동작합니다.
